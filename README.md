## Démarrage local

> Prérequis : [Node.js](https://nodejs.org) et [VS Code](https://code.visualstudio.com) avec l'[extension Claude Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code).

```bash
npm install
npm run dev
```

Le prototype est accessible sur http://localhost:5173

> En pratique, Claude démarre le serveur automatiquement au début de chaque conversation.
